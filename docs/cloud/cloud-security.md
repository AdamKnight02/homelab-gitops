## Common Security Recommendations

### For Production Use

1. **Restrict SSH access**: Use `/32` CIDR for your IP only
2. **Enable encryption**: Azure Disk Encryption, AWS EBS encryption
3. **Use private subnets**: For database and internal services
4. **Implement VPN**: Azure VPN Gateway or AWS Client VPN
5. **Use managed identity**: Azure Managed Identity or AWS IAM Roles
6. **Enable logging**: Azure Monitor or AWS CloudTrail
7. **Regular patching**: Automate OS updates
8. **Network segmentation**: Separate subnets for different tiers
9. **Secrets management**: Azure Key Vault or AWS Secrets Manager
10. **Terraform remote state**: Azure Storage or S3 with encryption

### For This Lab

Current security posture is **acceptable for a lab environment** with the following mitigations:

- No sensitive data in Terraform code
- No secrets in cloud-init
- EBS encryption enabled (AWS)
- Minimal IAM permissions
- Resource tagging for ownership
- Ephemeral flag for easy identification
